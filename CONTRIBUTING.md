# Contributing

Contributions to WormSwap's public documentation are welcome.

## Useful contributions

- Correct outdated links, product descriptions or deployment references.
- Improve explanations, diagrams and accessibility.
- Report reproducible interface issues with the affected route and browser/device details.
- Suggest product improvements with a concrete use case.

## Documentation changes

1. Open an issue or a focused pull request describing the problem.
2. Support changes to fees, addresses or deployment status with a public primary source.
3. Check relative links, tables, images and Mermaid diagrams in GitHub's preview.
4. Keep production availability separate from development plans.

The application source is maintained separately, so this documentation repository does not include a local application build or deployment command.

## Reports and sensitive information

Use the bug report template for ordinary issues. Include browser/OS versions and clear reproduction steps; remove personal data from attachments. Use [private security reporting](SECURITY.md) for suspected vulnerabilities.

Repository changes are reviewed by maintainers before acceptance.
