# Security Reporting

Report suspected WormSwap vulnerabilities privately to **[info@wormswap.finance](mailto:info@wormswap.finance)** with the subject **WormSwap security report**.

Include the affected component or public URL, observed behavior, impact and a minimal reproduction where available. Redact credentials and personal information. A report should not include a seed phrase, private key or live exploit against other users.

Public issues are suitable for ordinary documentation and interface feedback. Use private reporting for vulnerabilities that could expose funds, credentials or sensitive user data.

## Scope and disclosure

This repository publishes project documentation and deployment references. Verify contract addresses through the [contract guide](docs/CONTRACTS.md) and BscScan before relying on them. BscScan source verification and automated code review are distinct from an independent security audit.

Reports will be assessed by the project. This policy does not establish a bug bounty, guarantee a reward or promise a response time.
