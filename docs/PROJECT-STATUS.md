## Development priorities

- Improve routing reliability, transaction handling and token coverage within the supported BNB Chain integrations.
- Refine chart continuity, market-data behavior and the mobile trading experience.
- Continue Arena multiplayer, mobile performance and on-chain settlement testing before a public paid release.
- Maintain clear deployment references and transparent external data integrations.

These are development directions rather than dated delivery commitments. Release status should be updated here when a change is confirmed.

## Documentation maintenance

When product scope, deployment addresses, fee mechanics or integration status change, update this document and the corresponding guides together. DeFiLlama review comments and bot approval do not establish listing acceptance.
